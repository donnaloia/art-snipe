# ArtPipe Godot AI

A Docker-first, command-line driven starter repo for turning a gameplay mockup into game-ready asset candidates for a Godot roguelike deckbuilder.

This scaffold is intentionally practical:

- `make up` starts local services
- `make analyze MOCKUP=...` creates a screen analysis placeholder
- `make manifest` creates/validates an asset manifest
- `make segment` creates rough reference crops/placeholders
- `make generate` creates placeholder generated assets
- `make review` launches a simple local review UI placeholder
- `make export` copies approved assets into the Godot-style asset folder

The current version is a scaffold. The image model integrations are intentionally stubbed so you can wire in ComfyUI, SAM/SAM2, rembg, or hosted APIs later.

## Quick Start

```bash
make init
make up
make run MOCKUP=mockups/gameplay.png
make review
make export
```

## Folder Overview

```text
asset_pipeline/          Python CLI orchestration code
services/                Optional local services: SAM, review UI, etc.
workspace/               Intermediate files generated by the pipeline
godot_project/assets/    Final exported game assets
mockups/                 Put source gameplay mockups here
models/                  Local model weights, ignored by git
docs/                    Pipeline design notes
```

## Design Philosophy

This pipeline is not primarily about cutting assets out of mockups. It is about:

```text
mockup -> analysis -> manifest -> references -> generated candidates -> approval -> variants -> validation -> Godot export
```

The manifest is the source of truth. Segmentation creates references/placeholders. Generation creates production candidates.
